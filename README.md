This project is based on the code of Denis Lafourcade published in Elektor 7/2019 on page 56 [https://www.elektormagazine.de/magazine/elektor-99/50884] or in Elektor Labs [https://www.elektormagazine.de/labs/waterflow-monitor]. 
I changed the SMS sending via IFTT to sending emails over SMTP2GO as SMS sending is no longer available in IFTT and webhooks requires a paid subscription. 
I made many improvements and killed some bugs, so here is a working version of the software. For the hardware please look at the link to Elektor Magazine or Elektor Labs.
